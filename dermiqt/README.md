# Dermiqt – natural skincare demo store
Plain HTML, CSS and JavaScript. Open `index.html` – no install needed.

| File | Purpose |
|---|---|
| index.html | Page structure |
| css/style.css | Styling (colors are variables in `:root`) |
| js/app.js | Data, pictures, shop, cart, popup, forms (10 labelled parts) |

Customize products in the `PRODUCTS` array. Photos can be uploaded for the hero and each product.
Checkout is a demo: no payment, no account, no backend. Everything is fictional.
